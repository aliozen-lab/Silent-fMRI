This repository includes the radial gridding-based reconstruction code for the ZTE fMRI sequence used in the study published at IEEE TMI (doi:) and fMRI data processing pipeline. 
The sequence is available through Siemens' C2P platform, under the name "Silent fMRI"
If you use or get inspired by the code here, please cite: Özen AC, et al. Zero Echo Time Functional MRI in Humans: Technical Demonstration and Proof-of-Concept. IEEE TMI. 2026
